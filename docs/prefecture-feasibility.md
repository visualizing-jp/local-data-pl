# 広域自治体への適用可否（沖縄県）

調査日: 2026-09-12。対象は本ツールの Sankey（普通会計の歳入葉 → 自主／依存 → 合計 → 目的別＋形式収支）。検証団体は沖縄県。

## 結論

同じ骨格で都道府県も描ける。葉の集合は市町村と同一ではない。いまの八王子市用パーサをそのまま当てると、警察費と市町村への交付金歳出が落ちる。

| 論点 | 結果 |
| --- | --- |
| Sankey の骨格 | 使える。普通会計、自主／依存、目的別、形式収支 |
| 細目 | 一緒ではない。県に警察費と交付金歳出がある。市の交付金歳入・都道府県支出金は県の歳入葉にない |
| 直近データの形 | 総務省「財政状況資料集」Excel。都道府県版は全国47団体分が1か所にある |
| 古い年の e-Stat | 都道府県は別統計表。1989–2017。土木費・警察費の総額行は API 上空だった |
| パーマリンク | 全国地方公共団体コードのまま。沖縄県は `470007` |

沖縄県公式にも県本体の資料集があるが、掲載は 2017–2022 年度まで。

https://www.pref.okinawa.lg.jp/kensei/yosan/1015188/1015204.html

注意: 沖縄県サイトの「令和6年度 財政状況資料集」は県内市町村のファイルであり、県本体ではない。

## 細目の差

### 目的別歳出

都道府県は同じ並びのあと、**警察費**が土木費と消防費の間に入る。そのあと市町村へ渡す交付金が続く。

| 警察費 | ない | ある |
| 消防費 | ある | 科目はあるが 0 の年がある |
| 教育費〜前年度繰上充用金 | ある | ある |

## e-Stat（都道府県分）

調査コードは市町村と同じ `00200251`。統計表は別。

| 内容 | 統計表 ID | 備考 |
| --- | --- | --- |
| 歳入内訳 | `0003173301` | `cdTab=105900`、`cdArea=47000` |
| 歳出内訳及び財源内訳 | `0003173069` | `cdTab=201600`、`cdCat03=130` |

時間軸はどちらも **1989–2017 年度**（市町村分の 2018 までより1年短い）。

2017年度の沖縄県は、歳入葉の合計 735,773 百万円を API で取得できた。同じ条件で土木費・警察費・消防費の「総額」行（cat01 `1410` / `1520` / `1530`）は該当データなし。メタデータ上は項目がある。直近年度は資料集 Excel を正とし、e-Stat は古い年の補助と割り切る。

## 実装するときに触るところ

まだコードには入れてない。足すときは:

1. 目的別に警察費と交付金歳出を追加する（市町村の交付金歳入と名前が重なるので、歳入／歳出を混ぜない）。
2. 歳入葉に市町村たばこ税都道府県交付金を足し、都道府県支出金は県では使わない。
3. Excel パーサの税内訳列を「地方税の状況」だけでなく「道府県税の状況」も見る。
4. カタログに `code: "470007"`、`kind: "prefecture"` を足す。
5. 直近年度は総務省の都道府県資料集 Excel、1989–2017 は e-Stat 都道府県表。2018 年の隙間は資料集側で埋める。
