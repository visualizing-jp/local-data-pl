# データソース

八王子市の普通会計歳入・目的別歳出を、年度スライダーつき Sankey で描くための出典メモ。調査日: 2026-09-12。

## 1. 結論

一次出典は総務省「地方財政状況調査」（市町村別決算状況調）。団体コードは `132012`（e-Stat の市町村コードは `13201`）。単位は千円。収録年は **1989–2024 年度**。

| 期間 | 取得経路 |
| --- | --- |
| 2019–2024 | 八王子市「財政状況資料集」Excel のシート「普通会計の状況」 |
| 1989–2018 | e-Stat API の市町村分・歳入内訳／歳出内訳（目的別の総額） |

どちらも全国統一様式で、同じ調査の転記または API 配信である。

## 2. 検討して採用しなかった経路

| 経路 | 結果 |
| --- | --- |
| 図解財政の Sankey 画像 | 2022 年の静的画像のみ。数値テーブルなし。分類はサイト側の再集計 |
| デジタル庁 Japan Dashboard の flow CSV | 2020–2024 年があるが、歳入「その他」が粗い。商工費・消防費が欠ける。2022 歳入総額は 237,366 百万円で参照図と一致 |

## 3. 2019–2024（財政状況資料集）

https://www.city.hachioji.tokyo.jp/shisei/001/010/001/003/p007494.html

公開ページの一覧は 2020 年度以降だが、同じパスに令和元年度（`01zaiseijyoukyousyuu.xlsx`）もある。

| 年度 | ファイル |
| --- | --- |
| 2019 | `01zaiseijyoukyousyuu.xlsx` |
| 2020 | `02zaiseijyoukyousyuu.xlsx` |
| 2021 | `03zaiseijyoukyousyuu.xlsx` |
| 2022 | `04zaiseijyoukyousyuu.xlsx` |
| 2023 | `05zaiseijyoukyousyuu.xlsx` |
| 2024 | `06zaiseijyoukyousyuu.xlsx` |

パース対象は「普通会計の状況」。歳入は「歳入の状況」の葉、歳出は「目的別歳出の状況」の公式科目。性質別は使わない。2020 年の「地方特例交付金」は「地方特例交付金等」に正規化する。

## 4. 1989–2018（e-Stat）

調査コード `00200251`。団体は `cdArea=13201`。

| 内容 | 統計表 ID | 絞り込み |
| --- | --- | --- |
| 歳入葉 | `0003173261` | `cdTab=105900`（歳入額） |
| 歳出 その1（議会費・総務費） | `0003172923` | `cdCat03=130`（歳出合計） |
| 歳出 その2（民生費・衛生費） | `0003172943` | 同 |
| 歳出 その3（労働費・農林水産業費・商工費） | `0003172924` | 同 |
| 歳出 その4（土木費） | `0003172944` | 同 |
| 歳出 その5（消防費・教育費） | `0003172925` | 同 |
| 歳出 その6 2005–2018（災害復旧費・公債費・諸支出金・繰上充用金） | `0003172945` | 同 |
| 歳出 その6 1989–2004（同上） | `0003172926` | 同 |

目的別は「総額」行だけを使う。内訳行は落とす。取得には `ESTAT_APP_ID` が要る。

## 5. 検算（2022 年度）

参照図（図解財政、八王子市 2022）の総額 237,366 百万円と一致。

| 項目 | 資料集 | 参照図（歳入比） |
| --- | ---: | ---: |
| 歳入合計 | 237,366 百万円 | 237,366 百万円 |
| 地方税 | 39.1% | 39.1% |
| 民生費 | 48.3% | 48.3% |
| 形式収支 | 3.9% | 財政黒字 3.9% |

右側の中分類（行政運営・生活福祉・地域振興）は図解財政の再集計なので使わない。目的別（議会費・総務費・民生費…）をそのまま出す。

## 6. 出典表記

総務省「地方財政状況調査」（市町村別決算状況調）。2019 年度以降は八王子市「財政状況資料集」、2018 年度以前は e-Stat。
