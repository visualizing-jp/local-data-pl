# データソース

普通会計歳入・目的別歳出を、年度スライダーつき Sankey で描くための出典メモ。調査日: 2026-09-12。収録は東京都の区市町村（62）、神奈川県の市町村（33）、沖縄県の市町村（41）。

## 1. 結論

一次出典は総務省「地方財政状況調査」（市町村別決算状況調）。団体コードは `132012`（e-Stat の市町村コードは `13201`）。単位は千円。収録年は **1989–2024 年度**。

| 期間 | 取得経路 |
| --- | --- |
| 2019–2024 | 八王子市「財政状況資料集」Excel のシート「普通会計の状況」 |
| 1989–2018 | e-Stat API の市町村分・歳入内訳／歳出内訳（目的別の総額） |

どちらも全国統一様式で、同じ調査の転記または API 配信である。

## 2. 検討して採用しなかった経路

| 経路 | 結果 |
| --- | --- |
| 図解財政の Sankey 画像 | 2022 年の静的画像のみ。数値テーブルなし。分類はサイト側の再集計 |
| デジタル庁 Japan Dashboard の flow CSV | 2020–2024 年があるが、歳入「その他」が粗い。商工費・消防費が欠ける。2022 歳入総額は 237,366 百万円で参照図と一致 |

## 5. 検算（2022 年度）

参照図（図解財政、八王子市 2022）の総額 237,366 百万円と一致。

| 項目 | 資料集 | 参照図（歳入比） |
| --- | ---: | ---: |
| 歳入合計 | 237,366 百万円 | 237,366 百万円 |
| 地方税 | 39.1% | 39.1% |
| 民生費 | 48.3% | 48.3% |
| 形式収支 | 3.9% | 財政黒字 3.9% |

右側の中分類（行政運営・生活福祉・地域振興）は図解財政の再集計なので使わない。目的別（議会費・総務費・民生費…）をそのまま出す。

## 7. 広域自治体

都道府県でも同じ骨格は使えるが、葉は市町村と同一ではない。沖縄県での検証メモは [`prefecture-feasibility.md`](prefecture-feasibility.md)。県本体はまだカタログに入れていない。

## 8. 沖縄県内の基礎自治体

調査日: 2026-09-12。対象は現行 41 市町村。骨格・細目は八王子市と同じ市町村分。

| 期間 | 取得経路 |
| --- | --- |
| 2019–2024 | 沖縄県「財政状況資料集」（県内市町村 Excel）のシート「普通会計の状況」 |
| 現行団体コードで取れる年度–2018 | e-Stat API の市町村分・歳入内訳／歳出内訳（目的別の総額） |

Excel は県が全市町村分を公開している。令和6年度のファイル名に全国地方公共団体コードが入る（那覇市 `472018_naha_2024.xlsx`）。2019 年度は番号つきファイル名なので、ページ上の団体名で対応づける。

https://www.pref.okinawa.lg.jp/kensei/shinko/1016703/1016705/1016706/1022600/1016725/index.html

e-Stat の地域コードは団体コードの先頭 5 桁（那覇市 `47201`）。県の令和5年度名護市ファイルと令和3年度伊是名村ファイルは普通会計シートが欠けていたため、それぞれの団体サイトの資料集を使う。

廃置分合後の現行コードにデータがある年度だけを載せる。うるま市・宮古島市・南城市は 2005–、豊見城市・久米島町は 2002–、八重瀬町は 2005–。

パーマリンクは八王子市と同じ `?id=`（6桁）。那覇市は `/?id=472018`。

## 9. 東京都内の基礎自治体

調査日: 2026-09-12。対象は現行 62 区市町村（特別区 23、市 26、町村 13）。骨格・細目は市町村分と同じ。

| 期間 | 取得経路 |
| --- | --- |
| 2020–2024 | 東京都総務局「団体別資料集」の各団体ページにある財政状況資料集 Excel。シート「普通会計の状況」 |
| 2019 | 都の公開は直近5か年のため欠ける。八王子市だけ市サイトの資料集で埋める |
| 現行団体コードで取れる年度–2018 | e-Stat API の市町村分・歳入内訳／歳出内訳（目的別の総額） |

https://www.soumu.metro.tokyo.lg.jp/05gyousei/04kusichousonindex/04kusichousonzaisei/dantaibetsu/

廃置分合後の現行コードにデータがある年度だけを載せる。西東京市は 2000–、あきる野市は 1995–、羽村市は 1991–。2019 年度は都の公開対象外のため、特別区を含む都内団体（八王子市以外）は 2018 の次が 2020 になる。

資料集の「国有提供交付金(特別区財調交付金)」は、e-Stat では 19.国有提供施設等所在市町村助成交付金（`1910`）と 27.特別区財政調整交付金（`2450`）の2葉。同じ資料集の行に合わせて合算する。

パーマリンクは `?id=`（6桁）。千代田区は `/?id=131016`。八王子市は `/?id=132012`。
